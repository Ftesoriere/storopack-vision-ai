# 📦 Storopack Vision AI Analyzer

Sistema Cloud di analisi visiva automatica per l'identificazione dei materiali da imballaggio Storopack (**PAPERplus®**, **AIRplus®**, **FOAMplus®**, **PELASPAN®**) nei video YouTube.

---

## 🚀 Pubblicazione in Cloud (Gratuita su Streamlit Cloud)

1. Vai su **[share.streamlit.io](https://share.streamlit.io)** e accedi con il tuo account GitHub.
2. Clicca su **"New app"**.
3. Seleziona questo repository: **`Ftesoriere/storopack-vision-ai`**.
4. Clicca su **"Deploy!"**.
5. L'applicazione sarà online e raggiungibile a un link pubblico permanente.

---

## 🛠️ Struttura del Progetto

- **`app.py`**: Applicazione Web Streamlit con motore di analisi visiva dei frame reale.
- **`requirements.txt`**: Dipendenze Python necessarie.
- **`storopack_vision_analyzer_v2.html`**: Dashboard HTML stand-alone.
